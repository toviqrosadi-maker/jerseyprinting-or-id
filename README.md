# jerseyprinting.or.id — Zipzip Jersey Printing

Static HTML/CSS/JS website, ready for GitHub + Vercel.

## Deploy
1. Upload all files in this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: **Other** / static. No build command required.
4. Add custom domain `jerseyprinting.or.id` in Vercel.
5. Point DNS according to Vercel instructions.
